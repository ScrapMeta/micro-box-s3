# 一次性马达短振诊断

独立ESP-IDF5.4.3工程，目标ESP32-S3；GPIO14接集成驱动模块的IN，非裸马达功率输出。模块电源、逻辑兼容、保护及线序必须按实际器件核对；本例不能测电压/电流或保证硬件安全。

上电无自动脉冲，GPIO14在应用初始化时设为低。USB-Serial/JTAG控制台115200，命令字节：S查询状态，V触发一次200ms短振，X关闭。每次启动仅接受一次V，失败也不恢复额度。关闭由esp_timer任务执行，另保留X命令；复位过渡及调度故障不属于可证明的硬件限时保护。

GPIO11/12/13只配置输入，无触摸扫描；不运行按键/触摸业务、双眼、相机、音频或网络。不要以此固件替代小智集成功能。

独立构建：在导出SDK环境后，使用绝对项目路径和独立 `.build/motor-test` 目录、独立SDKCONFIG及本目录sdkconfig.defaults执行 `idf.py reconfigure build`。烧录前校验当前活动分区、已有引导程序与分区表兼容，备份当前应用和状态；不可直接照抄应用偏移或整板覆盖。写后独立回读应用摘要，验证保留区域，确认启动标记 `motor-once-v1` 后才发V。

本机单次功能记录见 [测试记录](../../docs/motor-test.md)。测试成功不证明低电量、温升、输入裕量或组合负载通过。
