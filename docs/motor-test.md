# 震动模块单次短振测试

## 实测结论

用户现有模块按 GPIO14→IN、VBAT→VCC、GND共地连接。本次实际烧录独立 `motor-once-v1` 测试固件，完成应用独立回读，保留原引导程序、分区表、OTA、NVS和PHY区域。

通过USB串口发送一次命令，日志记录一次 MOTOR_ON、一次 MOTOR_OFF；固件报告开启200020微秒，即200.020毫秒。用户现场确认：**“明显短振一下，然后停止”**。据此只认定本机现有连接条件下，单次启动/停止的基本功能通过。

完整镜像摘要、源码文件哈希和结果见 [motor-test.json](motor-test.json)。备份、设备标识与原始状态日志仅存本地忽略目录，没有上传。

## 测试模式及限制

- 应用启动后主动设GPIO14为低；不自动振动。只有串口V命令触发一次200ms定时脉冲；重复V被拒绝。X命令要求关闭，S查询状态。
- 一次触发额度在复位后重新建立，但复位本身不主动启动脉冲。软件不能证明复位瞬间物理电平无毛刺，也不能代替硬件默认关闭设计。
- 本阶段安装的是单次短振诊断固件；后续已更新为 [多时长/占空比测试固件](motor-patterns.md)。两者都不运行双按键/触摸业务、双眼动画、相机、语音或网络。
- 200.020ms来自固件定时记录，不是示波器测得的引脚脉宽或马达机械振动时长；软件定时器不是不可超时的硬件切断保护。
- 电池实际电压、电流、堵转保护、IN电平裕量/反灌、低电量启动、温升和组合负载均未测。一次成功不是全电量、长期可靠性或电气安全认证。
- 用户本轮明确要求马达测试；此前“马达始终断开”的假设已被用户澄清为一直连接。前一轮按键/触摸固件没有发出马达启动命令，本轮才首次下发短振。

需要恢复时使用本轮受影响扇区备份及相容的原固件；回读验证后再做现场确认。不要把固件中的基础版本号当作功能身份，应核对标记和镜像SHA-256。
