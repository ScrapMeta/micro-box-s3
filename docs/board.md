# 开发板说明

micro-box-s3 面向双眼显示、语音交互与相机应用。当前软件固定为 160×160 双屏，不承诺适配其他屏幕型号。GC9A01是软件驱动接口名称，屏模块实际控制器型号须以BOM或器件标识核实。

| 接口 | GPIO / 参数 |
|---|---|
| 屏1，SPI3 | SCLK42 / MOSI2 / RST1 / DC41 |
| 屏2，SPI2 | SCLK38 / MOSI39 / RST40 / DC0 |
| 两屏CS、MISO、背光控制 | 未定义可控GPIO（NC） |
| VB6824 | ESP32-S3 TX45 → 芯片RX；ESP32-S3 RX48 ← 芯片TX |
| 相机XCLK / SDA / SCL | 16 / 4 / 5 |
| 相机D0～D7 | 21、9、3、10、47、18、17、15 |
| 相机VSYNC / HREF / PCLK | 6 / 7 / 8 |
| 相机PWDN / RESET | 未定义（-1） |
| 触摸通道 | 仅GPIO11 / TOUCH11 |
| 机械按键A/B | GPIO12 / GPIO13，低电平按下 |
| 震动模块IN | GPIO14，高电平/PWM；默认idle，不是功率供电 |

上述是固件 GPIO/通道配置，机器可读定义见 `../board.json`，不代表插座的物理 Pin 顺序。

连接器清单、图纸针序、供电/通信规格及待核实项见 [接口手册](interfaces.md)。目前是图纸参考版，当前实物的版号、位置和 Pin 1 朝向尚待核对。

## 使用约束

- 使用USB供电和下载；主控GPIO按3.3V逻辑使用，不要把5V接入GPIO。连接器电源并不统一为3.3V：VBAT与相机多路电源须按接口手册分别核对。
- GPIO0兼作启动绑带与屏幕DC，复位期间不要随意拉低。
- 两屏占用SPI2、SPI3，不应重复初始化或未经协调复用总线。
- 背光没有独立PWM接口；NC不代表任意外接屏可以省略必要电源连接。
- VB6824必须已具备与本UART协议匹配的语音固件：输入OPUS、输出PCM；空白芯片不等同于可用模块。
- 本工程只构建ESP32-S3固件，不提供VB6824芯片固件烧写或网络升级服务。
- 两个外接常开按键和一路震动控制已分配GPIO；板载BOOT/RST不当作这两个业务键。电量、充电管理和电源关断接口仍未实现。
- 当前固件触摸只使用GPIO11；GPIO12/13给机械按键、GPIO14给马达IN，不能再用旧四路触摸固件混扫。接线/API见 [本地输入与震动](controls.md)。
