# 接口手册（图纸参考，待实物复核）

本章补充 micro-box-s3 的连接器清单、针序、功能和接线限制。固件 GPIO 配置见 [开发板说明](board.md) 与 `../board.json`。**GPIO 号、原理图 Pin 号、实物插头线序是三种不同信息，不可混用。**

## 1. 证据与适用范围

- 针序依据配套电路资料：原理图页 1～3、PCB 页 4、BOM 页 5；原理图日期为 2026-02-27，Revision 未填写。本文不分发原图或第三方硬件设计文件。
- 显示、相机和触摸的 GPIO 已与当前固件配置交叉核对；这只证明软件分配一致，不证明每个连接器已实装或针序已实测。
- 下表形式、间距均为图纸/BOM 标称。**尚未确认当前 0.71 英寸板的硬件版号、连接器位置、Pin 1 朝向、接触面、配套端子与压接线规格。不得把表的阅读方向当作插口从左到右的顺序。**
- 资料存在版本差异：相机页标注 OV2640，而已测传感器为 OV3660；耳机检测接点、PCB 附加器件与原理图/BOM 也不完全一致。本文不是已放行的装配或采购规格。

## 3. CN1 / CN2 / CN6：显示接口

| 原理图 Pin | CN1、CN6 | CN2 | 作用（相对主控） |
|---|---|---|---|
| 1 | 3.3V | 3.3V | 电源网络，电流预算未测 |
| 2 | GPIO41 | GPIO0 | DC，主控输出 |
| 3 | GPIO42 | GPIO38 | SCLK，主控输出 |
| 4 | GPIO2 | GPIO39 | MOSI，主控输出 |
| 5 | GPIO1 | GPIO40 | RESET，主控输出 |
| 6 | GND | GND | 地 |

- 固件配置：SPI mode 0、20 MHz、RGB565、160×160。20 MHz 是当前配置，不是连接器或任意屏模块的最高额定速率。GC9A01 是驱动接口名称，实际屏控制器须核实。
- 六个配线接点不含独立 CS、MISO 或背光 PWM；外接模块须匹配配套供电与使能方式，不能任意悬空额外引脚。
- 图纸中 CN1、CN6 同网且符号重叠；不能据此承诺两处同时插屏的负载能力，更不能独立输出不同画面。
- 图示焊脚 7、8 为额外固定脚并接 GND，不是第 7/8 根配线。
- GPIO0 同时关联启动绑带/BOOT 和屏 2 DC；不可任意拉低或作为普通按键复用。相同六针插头不保证不同分辨率、初始化序列的屏兼容。

## 4. CN4 / CN5：共享信号与通信引出

| 原理图 Pin | CN4 | CN5 |
|---|---|---|
| 1 | GPIO11 / TP1 / SERVO3 | RXD0 → GPIO44，主控接收 |
| 2 | GPIO12 / TP2 / SERVO4 | TXD0 ← GPIO43，主控发送 |
| 3 | GPIO13 / TP3 / SERVO1 | GPIO20，主控 USB D+ |
| 4 | GPIO14 / TP4 / SERVO2 | GPIO19，主控 USB D− |
| 5 | VBAT | VBAT |
| 6 | GND | GND |

- **Pin 5 是 VBAT，不是 3.3V，也不能当作 USB 5V/VBUS。** 未核对电源路径前，不从此脚输入外部电源或带负载。CN4/CN5 的 7/8 为固定焊脚，资料未见电气连接，不作为配线定义；不能照搬显示连接器固定脚接地的规则。
- CN4的四个GPIO同时连接历史触摸点及H1/H2；当前SDK只扫描GPIO11，GPIO12/13是机械按键，GPIO14是带驱动震动模块IN。SERVO只是网络别名，不代表舵机协议或功率输出。当前分配/接线与组件见 [本地输入与震动](controls.md)。不得再运行GPIO12/13/14参与扫描的旧四路触摸固件。
- CN5 的 UART0 与内部 VB6824 UART 不是同一接口；内部语音 UART 使用 GPIO45/48、2,000,000 baud。UART0 波特率/日志路由取决于固件配置，不保证此口自动有应用日志。
- UART0 是主控逻辑信号，不是 RS-232 电平接口。USB D+/D− 不是 UART TX/RX；它们与 USB1 共用主控 USB，不是第二个独立 USB 设备口，不可同时接入两个 USB 主机。

### H1 / H2：2×3 排针参考

| 原理图 Pin | H1 | H2 |
|---|---|---|
| 1、2 | GND | GND |
| 3、4 | VBAT | VBAT |
| 5 | SERVO2 / GPIO14 | SERVO4 / GPIO12 |
| 6 | SERVO1 / GPIO13 | SERVO3 / GPIO11 |

这是逻辑编号表，不是排针正面/背面的空间图。不得套用通用舵机三针线序、默认 5V 或固定舵机型号；电压、堵转电流和控制脉宽均未给定。

## 5. MX1 / MX2 / MX3：音频与电池

| 位号 | Pin 1（图纸） | Pin 2（图纸） | 功能与限制 |
|---|---|---|---|
| MX1 | MIC+，含语音芯片麦克风偏置路径 | GND | 模拟麦克风；偏置、阻抗和具体麦头未定，不能直接接数字麦克风 |
| MX2 | VOP，功放正端输出 | VON，功放负端输出 | 扬声器跨接两输出；**VON 不是地，不得接 GND**；阻抗/功率未确认 |
| MX3 | VBAT | GND | 电池接口；这是图纸极性，不代表已确认线束正反及实物 Pin 1 |

这些两针插座的其他焊脚不算信号针。不得按红黑线颜色、同款插头外观或其他模块习惯判断极性。MX1、MX2、MX3 不可互插。

图中出现 TP4057 充电电路，不代表已确认可用电池化学体系/串数、电压、容量、电流、反接保护、欠压保护、无电池启动或边充边用。本板未实现可用的电量读取/充电状态控制接口；通用基类虽有 `GetBatteryLevel` 占位方法，但默认返回 false，不代表本板支持；**确认电路与实物前，不把此表当作电池选型或接入许可。**

## 6. J1 / CN3：语音芯片 USB 与模拟音频

### J1（连接语音芯片，不连接主控 USB）

| 原理图 Pin | 网络 |
|---|---|
| 1 | GND |
| 2 | 3.3V |
| 3 | VB6824 USBDM |
| 4 | VB6824 USBDP |

Pin 2 不是标准 USB 的 5V/VBUS，不得直接套用普通四线 USB 线束。间距、Pin 1 朝向及专用工具接法待核实。本 SDK 不提供空白语音芯片初始化或升级服务，芯片须已具备匹配的固件。

### CN3（PJ-342，原理图焊盘编号）

| 焊盘号 | 资料定义 | 状态 |
|---|---|---|
| 2 | GND | 原理图与 PCB 网络一致 |
| 4 | 经 C28 隔直接 DACR | 原理图与 PCB 网络一致 |
| 5 | 经 C29 隔直接 DACR | 原理图与 PCB 网络一致 |
| 3、6 | 原理图未接 | 不当作可用外部信号 |
| 7 | 原理图未接；PCB 网络连接 R17/R24 与功放控制端 | **版本冲突，功能/极性未定** |

两个音频支路同源 DACR，不据此宣称独立立体声。焊盘号不是插头的 Tip/Ring/Sleeve 定义；插孔口径、插头制式、开关触点与自动静音行为尚未确认，不能按通用耳机口线序外接或声称插入检测已支持。

## 8. USB1 与板载触点/按键

### USB1 关键接点（原理图）

| 接点 | 网络/功能 |
|---|---|
| A1、A12、B1、B12 | GND |
| A4、A9、B4、B9 | VBUS，常规 USB 5V 供电场景 |
| A6、B6 | D+ → GPIO20 |
| A7、B7 | D− → GPIO19 |
| A5 / B5 | CC1 / CC2，经各自电阻到地 |
| A8 / B8 | SBU1 / SBU2，图中未接 |

USB1 用于主控下载/日志，不是 J1 的语音芯片 USB。未验证 PD、快充或外部供电反灌；不直接输入 9V/12V，也不在未核实电源路径时并接多路电源。

### 触点与按键（资料定义）

| 标记 | 网络 | 当前说明 |
|---|---|---|
| TP4 / DOT5 | GPIO14 / SERVO2 | 当前马达模块IN，不再作为触摸扫描 |
| TP3 / DOT6 | GPIO13 / SERVO1 | 当前机械按键B，不再作为触摸扫描 |
| TP2 / DOT7 | GPIO12 / SERVO4 | 当前机械按键A，不再作为触摸扫描 |
| TP1 / DOT8 | GPIO11 / SERVO3 | 当前唯一触摸通道 |
| BOOT1 | GPIO0 | 启动下载选择；与屏 2 DC 复用，不当作运行时业务按键 |
| RST1 | ESP_EN | 硬件复位，不是可分配的应用 GPIO |

PCB资料另出现BOOT2、D1、Q1、R2、R9、R14、R24、U2，未与原理图/BOM建立一致版本；不按附加位号推定当前实装、电源路径或新增按键功能。单触摸/双按键已有 [独立诊断响应记录](inputs-test.md)，震动已有 [独立短振对比](motor-patterns.md)，但本次新组件/小智适配、耳机、电池和扩展接口的整板/电气验收仍未完成。
